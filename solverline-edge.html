How this works
  1. Open this file in Safari, not the chat preview — the preview blocks live data.
  2. BE = breakeven: the win % a leg must clear before the payout makes money. Green box/bar = above it, red = below.
  3. Tap MLB or UFC. Games load with fair win % per side (de-vigged book consensus). Tap Load props on a game → every player prop shows as Over/Under boxes, already green (worth it) or red (pass).
  4. Set the payout once in the gold bar (e.g. 5.6 for a 5.6x boost). Every box is graded against it. Leave it blank and boxes grade against your slip's per-leg breakeven instead.
  5. Tap boxes to build a slip → Slip tab shows true parlay EV. Kalshi tab works the same: tap a series, tap a price, get a verdict.
